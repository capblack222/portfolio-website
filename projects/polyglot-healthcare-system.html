A healthcare records system using three databases, each chosen for the question it is actually good at answering.

the problem

Healthcare data arrives in three shapes at once. Patient records are relational and need to be correct above all else. Clinical notes and scan reports are documents with no fixed schema. Drug interactions are a graph, and the question asked of them — does anything this patient already takes conflict with what I am about to prescribe — is a traversal.

Forcing all three into one store means two of them are served badly. Interaction checking in particular degrades into recursive joins that get slower exactly as a patient’s medication list gets longer, which is precisely when the check matters most.

decisions

  • Matched each store to its access pattern. PostgreSQL for relational records, MongoDB for documents, Neo4j for the interaction graph. Three stores is a cost, and the justification is that each one answers a question the others answer poorly.
  • Named one system of record. PostgreSQL holds the truth. Polyglot persistence fails when two stores both believe they are authoritative, so the others are derived or supplementary by design.
  • Isolated SQL behind a repository layer. Clinical workflows compose without touching driver details, and the store behind a given operation can change without rewriting the logic above it.
  • Gated prescriptions on the traversal. The interaction check runs before a prescription reaches the system of record, so the graph is part of the write path rather than a report generated afterwards.

architecture

what I would change

There is no distributed transaction across the three stores, and there cannot easily be one. A write that should update PostgreSQL and MongoDB together can half-succeed, and the honest fix is not two-phase commit but making the non-authoritative writes idempotent and reconcilable from the system of record.

I would also want the interaction graph seeded from a maintained clinical dataset rather than from the catalogue I built by hand. The traversal is only as good as the edges in it.
